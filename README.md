# 我的知识库 · 参赛体验版

我的知识库是一款面向学习、创作与日常积累的本地记录工具。它支持固定方向与三级类目整理，可通过右键快速扩展目录，并提供大页面编辑、自动保存、搜索筛选、收藏、回收站、历史版本及完整备份。在线体验版的数据独立保存在当前浏览器，桌面版还支持自选资料与备份路径，帮助用户长期、安全地沉淀知识。

这是可部署到 GitHub Pages 的独立静态网页。每位访问者的记录保存在各自浏览器的 IndexedDB；初始内容全部是示例，没有作者的私人记录、附件或备份。

可体验三级知识类目、右键新增下级、记录编辑与自动保存、搜索筛选、回收站、历史版本和 JSON 备份。浏览器清理站点数据会清空本地体验记录。

桌面便携版源码与发布包留在原开发目录，未上传到此网页仓库。
